# 0003: Use Catch2 for tests

## Context

The project needs a C++ testing framework for TDD, with tests that are short and easy to read. Alternatives include GoogleTest, doctest, or writing checks without a testing framework.

## Decision

Use Catch2 3.8.1 for the C++ tests and fetch it through CMake FetchContent.

## Status

Proposed

## Consequences

Tests can be written as concise C++ test cases. Catch2 adds build time and requires internet access during the first configure.
